# Operational Architecture Portfolio

Public companion to my portfolio: system diagrams, case briefs, and AI-assisted workflow demonstrations for operationally complex, audit-sensitive environments.

All workflows preserve governance constraints, escalation boundaries, and human decision authority.

## Public Site

The full portfolio is published at [courtneypetersonchapman.notion.site](https://courtneypetersonchapman.notion.site/).

## Repository Approach

- Focus on system design, methodology, prompt architecture, workflow design, and illustrative outputs
- Show how AI-assisted workflows can structure reasoning without replacing accountable human judgment
- Keep examples public-safe, sanitized, and demonstration-oriented
- Preserve domain specificity without exposing proprietary source material
