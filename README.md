# My Portfolio

*Complexity isn't chaos: it's potential.*

I turn complexity into clarity, and clarity into measurable outcomes. I design operating systems for work that crosses processes, tools, and people—especially where ownership is unclear, handoffs break down, and evidence matters.

## How I work

I start with the problem, map how the parts connect, and find the change that matters downstream. I build systems that catch risk automatically and leave people the judgment calls. The goal is a system that can scale, sustain, and perform under real pressure.

This work spans Fortune 500 enterprises, high-growth startups, small businesses, and audit-sensitive federal environments. [See the visual portfolio](https://courtneypetersonchapman.notion.site/) for the designed presentation of the same work.
