# Security Policy

## Supported content

The current `main` branch is the maintained version of this portfolio. Downloaded
copies of briefs, slides, and diagrams may not reflect later corrections.

## Reporting a sensitive concern

If you find exposed credentials, private or controlled information, or another
sensitive issue in this repository, use GitHub's private vulnerability-reporting
channel for this repository. Do not disclose it in a public issue or pull request.

Include the affected file or link and a brief description that does not repeat
the sensitive content. Do not attach real case files, source selection information,
controlled data, credentials, or personal information.
